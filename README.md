## Goals

## Starter

## Environment

## Procedure
1. Write three beats: frame, one happy path, one recovery, close
2. Time it. Cut
3. Polish the README. Paste a real session if it’s missing
4. Clone your own repo in a clean folder (or ask a classmate). Follow the README
5. Draft the reflection for Practice 16
